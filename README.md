### 02 / [AISafe — Air Traffic Management System](https://github.com/1241182-AfonsoMachado/air-traffic-management-system-sem4)

**Software engineering & simulation · 4th semester**

An air traffic management and simulation system combining Java, C and PostgreSQL. It covers flight-related operations, TCP/UDP communication, automated testing and a separate simulation component.

`Java` `C` `PostgreSQL` `TCP/UDP` `Maven` `Testing`

### 03 / [Railway Logistics Management System](https://github.com/1241182-AfonsoMachado/railway-logistics-management-system-sem3)

**Algorithms, data & logistics · 3rd semester**

An integrated system for railway operations and warehouse logistics. It combines graph algorithms, railway network analysis, database operations and low-level programming components.

`Java` `C` `Oracle SQL/PLSQL` `RISC-V Assembly` `Graphs`

### 04 / [Railway Management Simulator](https://github.com/1241182-AfonsoMachado/railway-management-simulator-sem2)

**Desktop application & simulation · 2nd semester**

A railway management simulation game featuring stations, railway construction, locomotives and route planning. Developed in Java and JavaFX, with graph-based algorithms and supporting Python data analysis.

`Java` `JavaFX` `Dijkstra` `Graphs` `Python`

### 05 / [Eigenfaces — Face Recognition System](https://github.com/1241182-AfonsoMachado/eigenfaces-face-recognition-sem1)

**Algorithms & image processing · 1st semester**

A Java application based on the Eigenfaces method, using matrix operations, eigenvalues and eigenvectors for facial image reconstruction and identification through Euclidean distance.

`Java` `Linear Algebra` `Image Processing` `Algorithms`

### 06 / [Airport Campus Network Design](https://github.com/1241182-AfonsoMachado/airport-campus-network-design-sem4)

**Computer networks · 4th semester**

Design and simulation of a multi-terminal airport campus network using Cisco Packet Tracer, including VLANs, IPv4 addressing, OSPF routing and services such as DNS, DHCP and VoIP.

`Cisco Packet Tracer` `VLANs` `OSPF` `IPv4` `DNS/DHCP`
